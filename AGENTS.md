# DeskNames project instructions

Read PROJECT_CONTEXT.md before investigating or changing the application. Use README.txt for the detailed user guide and docs/architecture.md for source ownership.

Treat recorded test outcomes as historical. Verify the current source, build, and environment before reporting live behavior. Keep simulated geometry coverage separate from physical monitor validation.

Preserve personal preferences and saved layouts. Use isolated storage for native tests. Automatic routing is new-window-only, preserves later manual moves, and must not use a focus-changing drag fallback.

Desktop switching and native layout tests can visibly interrupt the user. Prefer background checks and run desktop-changing checks only when appropriate to the task. Preserve LICENSE and THIRD_PARTY_NOTICES.txt, including notices inside the built app.
